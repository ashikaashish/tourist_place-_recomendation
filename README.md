# Tourist Place Recommendation System

## Project Description
This project recommends tourist places using machine learning based on user interests.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit

## Files in Project
- tourist_places.csv → Dataset
- train_model.py → ML training file
- app.py → User interface
- recommendation_model.pkl → Saved model

## How to Run
1. Install required libraries
2. Run train_model.py
3. Run app.py
